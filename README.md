# 人物帖｜友達配布版（v13ベース）

探索者・思い出ギャラリー・召喚演出・技能検索ガチャ・思い出ガチャ・NFC/QR を含む、個人利用向けのPWAです。

## 公開する人へ

1. **自分用とは別の** GitHub リポジトリを新規作成します（例: `jinbutsucho-friends`）。
2. この ZIP にあるファイルを **すべてリポジトリのルートに** アップロードします。ZIPそのものをアップロードするのではありません。
3. GitHub → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` を選び保存します。
4. 公開URLを自分で開き、空の人物帖であること・新規探索者登録・思い出登録・召喚・ガチャ・QR表示を確認します。
5. 問題なければURLを友達に伝えます。

**重要**: GitHub Pages は認証付きの限定公開ではありません。URLが漏れたり検索に載ったりすれば第三者も利用できます。公開するのはアプリ本体だけにし、バックアップ JSON、探索者の個人データ、私的な画像、認証情報はアップロードしないでください。

## 友達へ

- 配布されたURLをスマホのブラウザで開いてください。ホーム画面に追加するとアプリ風に使えます。
- 初回は空の状態です。探索者や思い出は自分で登録します。
- データは基本的にそのブラウザ・サイトの保存領域（localStorage / IndexedDB）に残り、友達同士で自動共有されません。
- **定期的にバックアップ**を取ってください。ブラウザのデータ消去、端末故障、サイトURLの変更などでデータが失われることがあります。
- QRコード画像の生成時は、QRに入れるサイトURLが外部サービス（api.qrserver.com）に送られます。画像表示にはネット接続が必要です。
- NFC/QRで他の端末から探索者やアルバムを開くには、読み取り先の端末にも対象データが必要です。
- 友達がアプリを更新しても、同じURL・同じブラウザなら通常はデータを保持しますが、更新前のバックアップを推奨します。

## 配布内容の確認

- `index.html`：人物帖本体
- `summon.html`：探索者召喚・カード編集
- `sw.js`：オフライン利用用キャッシュ
- `manifest.webmanifest`：PWA設定
- `icon-*.png` / `apple-touch-icon.png`：アプリアイコン

元のv13からの機能変更はありません。友達用の別サイトで古いキャッシュと衝突しにくいよう、`sw.js` のキャッシュ名のみ更新しています。**実機での公開・NFC/QR・オフラインの動作は未検証**です。
